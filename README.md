# Worm Snake Game 🐛🎮

Worms Zone style arena game - Flutter APK ONLY, no website.

## Features
- Player worm with joystick + BOOST button
- 28 bot worms in 3200x3200 arena
- Food: fruits, fries, burger, cake, etc. Eat to grow + score
- Coins: collect 5 coins quest, earn coins for Wardrobe
- Leaderboard Top Players + your rank
- Quests: Eat 120 foods, Collect 5 coins
- Wardrobe: 8 Skins + 8 Faces, buy with coins, saved on phone
- Offline - no internet needed, no login

## Build (GitHub Actions - free, no PC)
1. Create NEW public GitHub repo `worm-snake-game`
2. Upload all files to repo ROOT (pubspec.yaml at root, lib/ folder, .github/workflows/build-apk.yml)
3. Push -> Actions tab -> Build Worm Snake APK -> download `worm-snake-apk` artifact
4. Install APK on phone (update existing install, do NOT uninstall)
